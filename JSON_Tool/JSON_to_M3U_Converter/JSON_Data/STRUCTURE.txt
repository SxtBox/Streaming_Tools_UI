1. Minimal Example (1 channel)
JSON
[
  {
    "group": "News",
    "name": "Example News",
    "logo": "https://example.com/logo.png",
    "tvg_id": "examplenews.us",
    "url": "http://stream.example.com/live/news.m3u8"
  }
]

3. Optional Fields Example
All fields except "url" are optional, but if omitted, their value will be empty in the M3U output.

JSON
[
  {
    "name": "Only URL Channel",
    "url": "http://stream.example.com/live/onlyurl.m3u8"
  },
  {
    "group": "General",
    "url": "http://stream.example.com/live/general.m3u8"
  }
]

4. Invalid Example (will NOT work)
JSON
{
  "channels": [
    { "name": "Bad Format", "url": "http://..." }
  ]
}

❌ This will not work. The top-level structure must be an array, not an object.

Summary Table
Field	Required?	Example Value
group	Optional	"News", "Sports", "Movies"
name	Optional	"Example TV"
logo	Optional	"https://example.com/logo.png"
tvg_id	Optional	"examplename.us"
url	Required	"http://stream.example.com/live/news.m3u8"
